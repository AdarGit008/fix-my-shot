**Seam** (`core` + `scoring`, sport-free): `PoseSnapshot` — the world reading of
one pose (named landmarks/directions/contacts, world COM, support polygon,
implement, stature, target direction; names supplied by the sport plugin, core
fixes only the container). `PrincipleResult.measured` — the honesty bit: a
principle the model cannot read is reported unmeasured, never deducted, never a
fix. Geometry primitives per the doc's "How each principle is measured": 3-point
angles, segment-vs-gravity, signed tilt, COM-in-support, target-plane lateral
offsets, distance-outside-hull. `measureAll` runs a sport plugin's `RecipeBook`
over the phase-appropriate principles only (qualitative rows carry no recipe by
design; a missing recipe for a measurable row throws).

**Aggregation** (ADR-0008 shape, constants = calibration parameters, documented
as such): written-in-stone violation caps the grade at `25 + 35·e^(−depth)`
(60 at zero depth, floor 25 — "an off-balance pose cannot read 82" holds
structurally); guideline bands deduct `25·(1 − e^(−0.6·depth))` with depth =
distance-outside ÷ band width — the smooth taper is deliberate: the score keeps
a live finite-difference gradient on gross violations instead of flat-lining,
which #12's leverage ranking needs; presence/direction/symmetry proxies deduct a
flat 12; failed style-variants are FLAGGED (satisfied=false, deduction 0).

**Recipes** (`basketball/src/measure.ts`): every measured principle of the
baseline. Criterion retags in `baseline.ts` deliver the file's "#11 refines"
promise, each with an inline comment: stance-width deducts on the row's own
never-penalized envelope 0.11–0.22 (deducting inside it would penalize in-range
style — acceptance #3); elbow-flare's envelope is 0–25 (only gross flare is a
fault; below-5° values are good); the loading leg-drive stone and four
gross-only rows became presence checks. Model-honesty: wrist-cocked and
wrist-snap-gooseneck return null (no wrist DOF — same posture as posegen);
repeatable-symmetric-geometry returns null (one frame has no history — #13's
territory); terminal-wrist-flexion reads its ARM fingerprint components (elbow
extended + upper arm held up), exactly the components the fault injector
perturbs.

**Calibration, the honest way**: dumped raw readings for all 33 shipped poses,
then set every engineering threshold BETWEEN the shipped clean values and the
injected faults, recorded in-line per constant. Two discoveries the dump forced:
(1) this skeleton's trunk vector tilts BACKWARD on a hunch (abdomen flexion
swings the pelvis forward under the free root) — the forward-flexion sign had to
flip, and the naive first thresholds caught nothing; (2) rebalanced
forward-collapse keeps the head's ground projection INSIDE the base (the legs
re-centre under it), so head-stabilized also reads the forward trunk fold —
without it the library's only forward-collapse pose surfaced nothing.
End state: **all 26 faulted poses read their injected principle** (stones cap
to 29.9–37.9; style faults flag at grade 100 — correct per acceptance #3), all
5 clean poses ≥ 95.9 with zero stones broken.

**Adapter** (`apps/web/src/measure/`): snapshots off the engine — landmarks from
body frames, torso-forward axis from xmat, world COM row 0 (ball included —
matches the gate authority), the gate's own footprint hull, sole/heel contact
flags from capsule endpoint heights (thresholds calibrated: balance-pass ankle
tilts lift heel endpoints to 0.056 m on legitimate poses), stature from the
model's standing pose (computed once per engine); save/restore discipline as
evaluateQpos. `gradeQpos(engine, phase, qpos)` is the re-grade entry point the
core loop calls (#14).

Known honest dings on synthetic clean poses (recorded, accepted): dip-clean
