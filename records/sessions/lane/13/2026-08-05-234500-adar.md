# Session — lane/13 — 2026-08-06

## Did

Built issue #13 — minimal v1 persistence, stacked on lane/12. Green: lint,
typecheck, 277 tests repo-wide (12 new), Vite build.

**Store** (`apps/web/src/progress/store.ts`, DOM- and engine-free): versioned
localStorage payload behind an injected `StorageLike` (tests run an in-memory
fake; the page passes `window.localStorage`). A "session" = one loaded pose
being worked on — re-grades UPSERT the same `sessionId`, so history reads one
line per sitting, not one per drag. Corrupt or future-versioned payloads read
as empty (cleared storage is a supported state, never an error); history caps
at 200 entries, oldest first out. Timestamps are caller-supplied ISO strings —
the store stays deterministic under test.

**Derivations**: `principleTrend` — the across-sessions series of a principle's
(satisfied, atStake) wherever it was actually measured (phases that don't
grade it contribute nothing). `topFixContinuity` — the ADR-0007 clause made
precise: the PREVIOUS session's top fix, compared against the LATEST later
session that measures its principle; improved = newly satisfied or
points-at-stake recovered; `null` (not false) when no later session re-measures
that phase — the view says "not re-measured yet" instead of lying either way.
The stored top fix keeps its cluster + cue, so history renders in the same
external-focus vocabulary as the report without recomputing anything.

**View** (`?history`, `ProgressPanel.tsx`): "pick up where you left off" card
(prior fix cue + improved / not-moved / awaiting-re-measure + a per-session
trend strip), the session table (when/pose/phase/grade/top fix), scaffold
framing in the footer copy, friendly empty state. Read-only by design —
recording is the loop's job (#14 calls `entryFromReport` on re-grade).

**Done-when held with real machinery**: an engine-backed test drives two real
sessions through the store — `dip-unloaded-straight-knee-00` (its report's top
fix recorded) then `dip-clean` (the fix embodied) — and asserts, reading a
fresh store over the same storage: the prior top fix comes back with its cue,
`improved === true` with the recovered points, the trend goes
unsatisfied→satisfied, and the grade movement shows in history.
